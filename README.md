# learn.local

Team NP Incomplete's project for the MTA Hacks 2026 hackathon.

This program provides a local database for classrooms, providing an alternative to online databases when internet access is limited or not desired.

Team Members: Alexander Matheson, Nathan Oakey, Jonah Bucci, Brenden Cosman


## Prerequisites

Ensure ```node``` and ```python``` are installed on your system.

## Setup

### Windows

In your command prompt do the following:
```
npm i
cd server
python -m pip install -r requirements.txt
cd..
cd frontend
npm i
cd ..
npm run dist
```

### MacOS/Linux

In your command prompt do the following:
```
npm i
cd server
python3 -m pip install -r requirements.txt
cd ..
cd frontend
npm i
cd ..
npm run dist
```

### Result

The built program should be into ./results
